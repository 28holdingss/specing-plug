# Specing Plug

Car upgrade website for **Specing Plug** — installation, interior & exterior upgrades, and parts (headlights, taillights, fenders, rims) across Honda, Toyota, Hyundai, Mercedes, Range Rover, BMW, Audi, and more.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Build

```bash
npm run build
npm run preview
```
